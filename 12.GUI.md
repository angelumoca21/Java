# 12.Entornos de desarrollo para crear aplicaciones gráficas

## 12.1.¿Qué es una aplicación gráfica?

Es un programa con interfaz visual (ventanas, botones, campos de texto, etc.)

Java ofrece varias tecnologías para crear interfaces gráficas:

- **Swing:** biblioteca clásica de Java para interfaces gráficas.
    ✔ Fácil para empezar
    ✔ Muy usada en enseñanza
    ❌ Diseño algo antiguo

- **JavaFX (moderna):** Framework más moderno para interfaces gráficas.
    ✔ Interfaces más bonitas
    ✔ Soporta CSS
    ✔ Animaciones
    ❌ Más complejo al inicio

- **AWT (antigua):** Framework más moderno para interfaces gráficas.
    ❌ Muy básica
    ❌ Ya casi no se usa
    ✔ Base de Swing

## 12.2.Componentes gráficos básicos

| Componente | Clase        |
| ---------- | ------------ |
| Ventana    | `JFrame`     |
| Botón      | `JButton`    |
| Texto      | `JLabel`     |
| Entrada    | `JTextField` |

```
import javax.swing.*;

public class VentanaBasica {

    public static void main(String[] args){

        // Crear ventana
        JFrame ventana = new JFrame("Ejemplo GUI");
        ventana.setSize(300, 200);
        ventana.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        // Usar layout simple
        ventana.setLayout(null);

        // Crear componentes

        JLabel etiqueta = new JLabel("Nombre:");
        etiqueta.setBounds(20, 20, 100, 20);

        JTextField campoTexto = new JTextField();
        campoTexto.setBounds(100, 20, 150, 20);

        JButton boton = new JButton("Aceptar");
        boton.setBounds(100, 60, 100, 30);

        // Agregar componentes a la ventana
        ventana.add(etiqueta);
        ventana.add(campoTexto);
        ventana.add(boton);

        // Mostrar ventana
        ventana.setVisible(true);
    }
}
```

### 12.2.1.Eventos

Un evento ocurre cuando el usuario hace algo (clic, escribir, etc.)

```
import javax.swing.*;
import java.awt.event.*;

public class VentanaInteractiva {

    public static void main(String[] args){

        JFrame ventana = new JFrame("Formulario");
        ventana.setSize(300, 200);
        ventana.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        ventana.setLayout(null);

        // Componentes
        JLabel etiqueta = new JLabel("Nombre:");
        etiqueta.setBounds(20, 20, 100, 20);

        JTextField campoTexto = new JTextField();
        campoTexto.setBounds(100, 20, 150, 20);

        JButton boton = new JButton("Saludar");
        boton.setBounds(100, 60, 100, 30);

        // Evento del botón
        boton.addActionListener(new ActionListener() {
            public void actionPerformed(ActionEvent e){

                String nombre = campoTexto.getText();

                JOptionPane.showMessageDialog(null, "Hola " + nombre);

            }
        });

        // Agregar componentes
        ventana.add(etiqueta);
        ventana.add(campoTexto);
        ventana.add(boton);

        ventana.setVisible(true);
    }
}
```
