# 10.Estructuras de datos

Una estructura de datos es una forma de organizar y almacenar datos para poder usarlos eficientemente.

## 10.1.Estructuras de datos principales

### 10.1.1.ArrayList

Es una lista basada en arreglo dinámico.

Características:

✔ Acceso rápido por índice
✔ Tamaño dinámico
❌ Insertar/eliminar en medio es más lento

Usar cuando se necesita:

- Acceso por índice
- Recorrer datos
- Listas normales

```
ArrayList<TipoDatos> nombreLista = new ArrayList<TipoDatos>();
nombreLista.add("A");
nombreLista.add("B");

System.out.println(nombreLista.get(0)); // A
```

[Más información sobre ArrayLists](https://www.w3schools.com/java/java_arraylist.asp)

### 10.1.2.LinkedList

Lista enlazada (cada elemento apunta al siguiente).

Características:

✔ Insertar/eliminar rápido
❌ Acceso por índice lento

Usar cuando se necesita:

Realizar muchas inserciones/eliminaciones

```
LinkedList<TipoDatos> nombreLista = new LinkedList<TipoDatos>();

nombreLista.add("A");
nombreLista.add("B");
```

[Más información sobre LinkedLists](https://www.w3schools.com/java/java_linkedlist.asp)

### 10.1.3.Stack (Pila LIFO)

```
Stack<TipoDatos> nombrePila = new Stack<>();

nombrePila.push(10);
nombrePila.push(20);

System.out.println(nombrePila.pop()); // 20
```

### 10.1.4.Queue (Cola FIFO)

```
Queue<TipoDatos> cola = new LinkedList<>();

cola.add("A");
cola.add("B");

System.out.println(cola.poll()); // A
```
